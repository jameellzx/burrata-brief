How it works

  1. Every week, check each campaign.
  2. Ads with the lowest cost per result and the best numbers move to Winners.
  3. Move them with the same post ID, so likes and comments stay.
  4. Winners gets more money: start at 50 KD, then shift 10–20% from the weakest campaign.
  5. Wait ~7 days before judging any ad (learning phase).
